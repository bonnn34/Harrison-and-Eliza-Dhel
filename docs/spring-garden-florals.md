## Shared generation prompt

Use case: stylized-concept. Production raster ornament for a wedding website. Input image is a STYLE REFERENCE ONLY: the approved Spring Garden concept board. Match its exact delicate hand-painted botanical watercolor, translucent petals, thin natural stems, airiness and refined wedding stationery illustration. Palette: blush pink #F3CED6 peony/rose, butter yellow #F7E5A9 cosmos/daisies, small dusty blue #5B7FA6 flowers lightened by cream, lavender #DCCFF0 sprigs, soft sage #A9B9A1 foliage. Include all five tastefully. Genuine transparent alpha background. No paper, cream backdrop, checkerboard, text, labels, typography, frame, shadow, watermark, burgundy, red or dark olive. This must be an isolated finished ornament, not a design board or screenshot. Entire painting fully inside canvas, crisp detailed edges, no clipped leaves, no extra objects.
